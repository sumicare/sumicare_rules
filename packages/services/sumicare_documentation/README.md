# Gitops

A GitOps service providing continuous delivery and infrastructure-as-code reconciliation for the Sumicare platform.

Part of **rules_sumicare** — a collection of reusable Bazel rules for platform engineering implementing Reference Cloud Native Architecture (RCNA) patterns and practices.

## Overview

This service (`@sumicare/gitops`) is a component of the Sumicare platform engineering toolkit.
