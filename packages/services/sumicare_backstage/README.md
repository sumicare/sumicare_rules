# Backstage

A Backstage developer portal service providing a unified platform for service catalog, documentation, and developer experience.

Part of **rules_sumicare** — a collection of reusable Bazel rules for platform engineering implementing Reference Cloud Native Architecture (RCNA) patterns and practices.

## Overview

This service (`@sumicare/backstage`) is a component of the Sumicare platform engineering toolkit.
