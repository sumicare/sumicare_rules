# Sumicare Office Worker

Manages local office development environments for the Sumicare platform.

Adds local office machines to a development cluster, allowing creating an managing k8s development clusters with [k8s cluster manager](../sumicare_k8s_cluster_manager/), sharing and scaling a set of Bazel Workers and Build Cache.

Part of **rules_sumicare** — a collection of reusable Bazel rules for platform engineering implementing Reference Cloud Native Architecture (RCNA) patterns and practices.

## Overview

This service (`@sumicare/office-worker`) is a component of the Sumicare platform engineering toolkit.
