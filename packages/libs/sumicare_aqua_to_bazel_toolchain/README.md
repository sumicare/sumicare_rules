# Aqua To Bazel Toolchain

Derives Bazel toolchains from the [Aqua](https://github.com/aquaproj/aqua-registry) registry.

Much like [mise](https://mise.jdx.dev/) integrates with [Aquaproj](https://aquaproj.github.io/), this library renders `registry.yaml` entries as Bazel toolchain definitions.

## Overview

This library (`@sumicare/aqua-to-bazel-toolchain`) is a component of the Sumicare platform engineering toolkit.
