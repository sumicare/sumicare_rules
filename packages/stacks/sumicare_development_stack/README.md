# Development Stack

Kubernetes development stack providing CI/CD, source control, and cloud IDE infrastructure for developer workflows.

Part of **sumicare_rules** — a Bazel-based framework for building and deploying applications together with their platform infrastructure, implementing Reference Cloud Native Architecture (RCNA) patterns and practices.

## Overview

This stack (`@sumicare/development-stack`) is a component of the Sumicare platform engineering toolkit.
