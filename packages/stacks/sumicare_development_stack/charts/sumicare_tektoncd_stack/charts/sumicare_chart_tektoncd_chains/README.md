Tekton Chains — a Kubernetes CRD controller for supply chain security that signs TaskRun and PipelineRun results, generating SLSA provenance attestations with support for multiple storage backends.

Part of **sumicare_rules** — a Bazel-based framework for building and deploying applications together with their platform infrastructure, implementing Reference Cloud Native Architecture (RCNA) patterns and practices.

## Overview

This chart (`@sumicare/tektoncd-chart-chains`) is a component of the Sumicare platform engineering toolkit.
