Tekton Dashboard — a web-based UI for managing and viewing Tekton Pipelines and Triggers resources, including realtime PipelineRun/TaskRun status, logs, and resource YAML inspection.

Part of **sumicare_rules** — a Bazel-based framework for building and deploying applications together with their platform infrastructure, implementing Reference Cloud Native Architecture (RCNA) patterns and practices.

## Overview

This chart (`@sumicare/tektoncd-chart-dashboard`) is a component of the Sumicare platform engineering toolkit.
