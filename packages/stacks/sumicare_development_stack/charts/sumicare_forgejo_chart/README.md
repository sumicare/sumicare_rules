Forgejo — a community-governed, self-hosted git forge (fork of Gitea) providing source control, CI/CD pipelines, and package registries, running as a lightweight Go binary on Kubernetes.

Part of **sumicare_rules** — a Bazel-based framework for building and deploying applications together with their platform infrastructure, implementing Reference Cloud Native Architecture (RCNA) patterns and practices.

## Overview

This chart (`@sumicare/forgejo-chart`) is a component of the Sumicare platform engineering toolkit.
