Grafana Pyroscope — an open source continuous profiling database for observability, providing flame graph visualization and profiling data storage for CPU, memory, and goroutine analysis of applications.

Part of **sumicare_rules** — a Bazel-based framework for building and deploying applications together with their platform infrastructure, implementing Reference Cloud Native Architecture (RCNA) patterns and practices.

## Overview

This chart (`@sumicare/pyroscope-chart`) is a component of the Sumicare platform engineering toolkit.
