# Observability Stack

Kubernetes observability stack providing metrics, logs, traces, and profiling collection with visualization dashboards.

Part of **sumicare_rules** — a Bazel-based framework for building and deploying applications together with their platform infrastructure, implementing Reference Cloud Native Architecture (RCNA) patterns and practices.

## Overview

This stack (`@sumicare/observability-stack`) is a component of the Sumicare platform engineering toolkit.
