# Finops Stack

Kubernetes FinOps stack providing cost monitoring, resource allocation visibility, and cloud spend optimization.

Part of **sumicare_rules** — a Bazel-based framework for building and deploying applications together with their platform infrastructure, implementing Reference Cloud Native Architecture (RCNA) patterns and practices.

## Overview

This stack (`@sumicare/finops-stack`) is a component of the Sumicare platform engineering toolkit.
