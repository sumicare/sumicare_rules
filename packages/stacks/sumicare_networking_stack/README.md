# Networking Stack

Kubernetes networking stack providing CNI, service mesh, DNS management, and network policy enforcement.

Part of **sumicare_rules** — a Bazel-based framework for building and deploying applications together with their platform infrastructure, implementing Reference Cloud Native Architecture (RCNA) patterns and practices.

## Overview

This stack (`@sumicare/networking-stack`) is a component of the Sumicare platform engineering toolkit.
