NetBird — open-source Zero Trust Networking platform that creates secure WireGuard®-based overlay networks with SSO, MFA, and granular access controls, replacing traditional VPNs with identity-based peer-to-peer connectivity.

Part of **sumicare_rules** — a Bazel-based framework for building and deploying applications together with their platform infrastructure, implementing Reference Cloud Native Architecture (RCNA) patterns and practices.

This chart (`@sumicare/stack-networking-netbird`) is a component of the Sumicare platform engineering toolkit.
