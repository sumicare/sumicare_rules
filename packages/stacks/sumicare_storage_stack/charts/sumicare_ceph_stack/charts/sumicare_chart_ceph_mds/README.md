Ceph metadata server — the Ceph MDS daemon deployment providing metadata management for CephFS, the POSIX-compliant distributed file system built on top of the Ceph RADOS object store.

Part of **sumicare_rules** — a Bazel-based framework for building and deploying applications together with their platform infrastructure, implementing Reference Cloud Native Architecture (RCNA) patterns and practices.

## Overview

This chart (`@sumicare/chart-storage-ceph-mds`) is a component of the Sumicare platform engineering toolkit.
