Ceph stack — a comprehensive distributed storage deployment providing Ceph monitors (MON), managers (MGR), object storage daemons (OSD), RADOS Gateway (RGW) for S3-compatible object storage, and metadata servers (MDS) for CephFS.

Part of **sumicare_rules** — a Bazel-based framework for building and deploying applications together with their platform infrastructure, implementing Reference Cloud Native Architecture (RCNA) patterns and practices.

## Overview

This chart (`@sumicare/ceph-stack`) is a component of the Sumicare platform engineering toolkit.
