Valkey Operator — a Kubernetes operator for managing Valkey (open source Redis-compatible key-value store by Linux Foundation) clusters with automated provisioning, failover, scaling, and configuration.

Part of **sumicare_rules** — a Bazel-based framework for building and deploying applications together with their platform infrastructure, implementing Reference Cloud Native Architecture (RCNA) patterns and practices.

## Overview

This chart (`@sumicare/valkey-operator-chart`) is a component of the Sumicare platform engineering toolkit.
