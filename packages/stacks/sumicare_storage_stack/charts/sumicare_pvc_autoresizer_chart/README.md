PVC Autoresizer — automatically resizes PersistentVolumeClaims when free storage falls below a threshold, using Prometheus metrics or Kubernetes Metrics API to monitor volume usage and prevent disk exhaustion.

Part of **sumicare_rules** — a Bazel-based framework for building and deploying applications together with their platform infrastructure, implementing Reference Cloud Native Architecture (RCNA) patterns and practices.

## Overview

This chart (`@sumicare/pvc-autoresizer-chart`) is a component of the Sumicare platform engineering toolkit.
