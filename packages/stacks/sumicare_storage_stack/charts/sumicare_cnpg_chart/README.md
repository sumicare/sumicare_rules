CloudNativePG (CNPG) — a Kubernetes operator for PostgreSQL providing high-availability clusters with automated failover, continuous WAL archiving, point-in-time recovery, and native volume snapshot backup.

Part of **sumicare_rules** — a Bazel-based framework for building and deploying applications together with their platform infrastructure, implementing Reference Cloud Native Architecture (RCNA) patterns and practices.

## Overview

This chart (`@sumicare/cnpg-chart`) is a component of the Sumicare platform engineering toolkit.
