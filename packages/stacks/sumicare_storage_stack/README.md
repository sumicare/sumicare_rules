# Storage Stack

Kubernetes storage stack providing persistent volume management, object storage, database operators, and backup/restore.

Part of **sumicare_rules** — a Bazel-based framework for building and deploying applications together with their platform infrastructure, implementing Reference Cloud Native Architecture (RCNA) patterns and practices.

## Overview

This stack (`@sumicare/storage-stack`) is a component of the Sumicare platform engineering toolkit.
