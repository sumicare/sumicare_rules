Argo Events — an event-driven workflow automation framework for Kubernetes that triggers K8s objects, Argo Workflows, and serverless workloads from 20+ event sources including webhooks, S3, messaging queues, and schedules.

Part of **sumicare_rules** — a Bazel-based framework for building and deploying applications together with their platform infrastructure, implementing Reference Cloud Native Architecture (RCNA) patterns and practices.
