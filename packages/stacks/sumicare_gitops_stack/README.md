# Gitops Stack

Kubernetes GitOps stack providing declarative continuous delivery, progressive deployment, and workflow automation.

Part of **sumicare_rules** — a Bazel-based framework for building and deploying applications together with their platform infrastructure, implementing Reference Cloud Native Architecture (RCNA) patterns and practices.

## Overview

This stack (`@sumicare/gitops-stack`) is a component of the Sumicare platform engineering toolkit.
