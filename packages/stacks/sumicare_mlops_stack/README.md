# Mlops Stack

Kubernetes MLOps stack providing LLM serving, distributed training, GPU scheduling, and model lifecycle management.

Part of **sumicare_rules** — a Bazel-based framework for building and deploying applications together with their platform infrastructure, implementing Reference Cloud Native Architecture (RCNA) patterns and practices.

## Overview

This stack (`@sumicare/mlops-stack`) is a component of the Sumicare platform engineering toolkit.
