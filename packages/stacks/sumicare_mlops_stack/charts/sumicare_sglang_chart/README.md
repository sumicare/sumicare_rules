SGLang — a high-throughput inference engine for large language models with cache-aware load balancing, multi-node deployment, prefill-decode disaggregated serving, and multi-LoRA adapter support.

Part of **sumicare_rules** — a Bazel-based framework for building and deploying applications together with their platform infrastructure, implementing Reference Cloud Native Architecture (RCNA) patterns and practices.

This chart (`@sumicare/sglang-chart`) is a component of the Sumicare platform engineering toolkit.
