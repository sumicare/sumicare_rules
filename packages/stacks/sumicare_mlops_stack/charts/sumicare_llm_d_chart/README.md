llm-d — a high-performance distributed LLM inference serving stack for Kubernetes, providing prefix-cache-aware routing, disaggregated prefill-decode serving, and intelligent inference scheduling above vLLM and SGLang.

Part of **sumicare_rules** — a Bazel-based framework for building and deploying applications together with their platform infrastructure, implementing Reference Cloud Native Architecture (RCNA) patterns and practices.
