OME (Open Model Engine) — a Kubernetes operator for enterprise-grade LLM serving with GPU scheduling, model lifecycle management, and runtime integrations for SGLang, vLLM, TensorRT-LLM, and Triton.

Part of **sumicare_rules** — a Bazel-based framework for building and deploying applications together with their platform infrastructure, implementing Reference Cloud Native Architecture (RCNA) patterns and practices.

This chart (`@sumicare/ome-chart`) is a component of the Sumicare platform engineering toolkit.
