# Data Stack

Kubernetes data stack providing event streaming, pub/sub messaging, and event-driven communication infrastructure.

Part of **sumicare_rules** — a Bazel-based framework for building and deploying applications together with their platform infrastructure, implementing Reference Cloud Native Architecture (RCNA) patterns and practices.

## Overview

This stack (`@sumicare/stack-data`) is a component of the Sumicare platform engineering toolkit.
