# Security Stack

Kubernetes security stack providing certificate management, secrets management, policy enforcement, and runtime security.

Part of **sumicare_rules** — a Bazel-based framework for building and deploying applications together with their platform infrastructure, implementing Reference Cloud Native Architecture (RCNA) patterns and practices.

## Overview

This stack (`@sumicare/security-stack`) is a component of the Sumicare platform engineering toolkit.
