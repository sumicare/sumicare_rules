KubeArmor — a cloud-native runtime security enforcement system that restricts process execution, file access, and networking operations of pods and containers using Linux Security Modules (AppArmor, SELinux, BPF-LSM).

Part of **sumicare_rules** — a Bazel-based framework for building and deploying applications together with their platform infrastructure, implementing Reference Cloud Native Architecture (RCNA) patterns and practices.
